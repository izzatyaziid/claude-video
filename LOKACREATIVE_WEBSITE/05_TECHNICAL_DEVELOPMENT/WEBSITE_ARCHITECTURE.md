# Website Architecture
> **Peraturan:** tiada fakta, angka, revenue, klien atau pencapaian rekaan. `TBC` = belum disahkan. **CADANGAN** = idea perancangan yang perlu approval, bukan fakta.

## Struktur halaman
Rujuk [`SITEMAP.md`](../02_WEBSITE_STRATEGY/SITEMAP.md).

## CADANGAN model kandungan
| Entiti | Medan |
|---|---|
| **Brand** | nama, slug, logo, fungsi (1 ayat), penerangan, warna, pautan (website/IG/FB), status (aktif/akan datang), susunan |
| **Page** | tajuk, slug, bahasa, SEO (title, description, OG image), blok kandungan |
| **Inquiry** (borang) | nama, emel, syarikat, jenis, mesej, persetujuan PDPA, cap masa |

## Persekitaran (CADANGAN)
`preview` (setiap perubahan) → `production` (hanya selepas approval). Kod website akan disimpan dalam folder berasingan (lokasi TBC, contoh `LOKACREATIVE_WEBSITE/site/`) **selepas** perancangan diluluskan.
