# UI / UX Guidelines
> **Peraturan:** tiada fakta, angka, revenue, klien atau pencapaian rekaan. `TBC` = belum disahkan. **CADANGAN** = idea perancangan yang perlu approval, bukan fakta.

## Standard asas (dicadangkan sebagai wajib)
- **Mobile-first.** Kebanyakan trafik dijangka dari media sosial (andaian: perlu disahkan dengan data analytics bila ada).
- **Kebolehcapaian:** WCAG 2.2 AA. Navigasi papan kekunci, alt text, label borang, fokus yang jelas.
- **Prestasi:** sasaran Core Web Vitals "Good" (LCP ≤ 2.5 s, INP ≤ 200 ms, CLS ≤ 0.1).
- **Navigasi:** maksimum 5–6 item utama. Jenama boleh dicapai dalam 1 klik dari Home.
- **Laluan keluar ke jenama:** setiap kad jenama jelas sama ada ia membuka halaman dalaman atau saluran luar (ikon external link).
- **Borang:** pendek, dengan persetujuan privasi (PDPA Malaysia); simpan data hanya yang perlu.
- **Motion:** halus, hormati `prefers-reduced-motion`.

## Komponen utama (CADANGAN)
Header + nav · Hero · Kad jenama (logo, satu ayat fungsi, CTA) · Blok "tentang kumpulan" · CTA kerjasama · Footer (pautan jenama, sosial, privasi)
