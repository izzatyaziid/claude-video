## PHASE 1 — CREATIVE CONCEPT

### "SIGNAL / NOISE"
Most businesses are not short of content. They are drowning in it. The film turns that idea into one visual metaphor that LOKADIGITAL can own:

> **Content without insight is noise. A system turns it into signal.**

The film starts in **noise**: a storm of posts, notifications and vanity metrics speeding up until it seizes. It cuts to silence and the truth. Then all the chaos collapses into one clean **electric-yellow line, the Signal**. That line becomes the spine of the LOKADIGITAL System (AUDIT → POSITION → CREATE → TEST → ADVERTISE → SCALE). At the end it shrinks into the full stop of *"A SYSTEM IS."* and that same dot becomes the line under the logo.

**Why it works for the brand**
- The positioning is "strategy based on insights and data", so a picture of signal pulled out of noise says it without explaining.
- It gives a **repeatable identity device** for future episodes: the yellow Signal Line. It is always the only yellow element of meaning on screen, and it always means "this is what matters".
- It makes LOKADIGITAL look like the calm, analytical one in the room, not another agency shouting about virality.

### Visual identity system (reusable across the series)
| Element | Rule |
|---|---|
| Base | Ink black `#05030A`, never flat. Lit by slow-drifting deep-purple ambient light (`#602AC8` → `#301270`). |
| Accent | Electric yellow `#E8FF2B`. Used **only** for signal: the insight, the winner, the system, the brand. Never decoration. |
| Secondary | Lavender `#AB94FF` for supporting data, Mist `#D4CAF2` for body copy, Grey `#7C7396` for meta labels. |
| Display type | Inter Display Black/ExtraBold, tight tracking (−0.04 em), hard masked reveals (text rises from behind an invisible edge). |
| Body / labels | Inter Medium for copy; Inter SemiBold, ALL CAPS, +0.28 em tracking for HUD/meta labels. |
| Motion | Expo-out entrances, expo-in exits, nothing linear. Impacts carry a camera kick (shake + 2–7 % zoom) plus a bloom flash. |
| Finish | Film grain (overlay 16 %), vignette, low-res bloom pass, controlled glitch only at moments of breakdown. |
| Sound | Dark D-minor bed with a sub-heavy pulse. Every visual action has a matched sound; silence is used as a weapon. |

Everything below was built for this film, procedurally, in code. No stock footage, no AI images, no templates.

| Content-vs-sales chart, gap fill | Canvas 2D | `sChart` |
| Noise field (64 traces) + trend fragments | Procedural | `sNoise` |
| Signal line + light pulse | Procedural | `sNoise`, `sRail`, `sBrand` |
| System rail + 6 stage data-visuals | Procedural | `sRail`, `vAudit` … `vScale` |
| LOKADIGITAL wordmark lock-up + reflection + gleam | Typographic build in Inter Display | `markL`, `drawMark`, `sBrand` |
| Film grain plates ×6, vignette, bloom, glitch | Procedural post | `initAssets`, `post` |
| Score + ~150 sound effects | numpy synthesis (kick, sub-boom, whoosh, riser, glitch, ping, pad, bass) + convolution reverb, tape-stop, ducking | `audio/sound.py` |

## PHASE 5 — VIDEO PRODUCTION (pipeline)

```
render/scene.js   → deterministic renderFrame(t), 1770 frames @30fps
render/render.js  → headless Chromium (Playwright), 4 parallel workers
audio/sound.py    → 48 kHz stereo score, locked to the same timeline constants
build.sh          → x264 (CRF 17, tune grain, high profile) + AAC 256k, −14 LUFS, faststart
```
Rebuild everything with: `./ep01/build.sh` (about 1–2 min).
