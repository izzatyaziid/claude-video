## Butiran setiap idea

### C01 ★ — "Boost Post Bila Sales Turun?" (SAMPLE 01 · character-led)
| | |
|---|---|
| **Hook** | Watak menekan butang BOOST, duit mengalir keluar dari dompet, dan keningnya terangkat |
| **Insight** | Ramai pemilik bisnes "boost" post secara reaktif bila jualan jatuh. Likes naik, tetapi jualan tidak berubah, kerana tiada sasaran, ujian atau sistem |
| **Audiens** | SME & F&B owners |
| **Objektif** | Kesedaran masalah, kemudian memperkenalkan pemikiran "uji dulu, baru besarkan" |
| **Storytelling** | Boost → hati beterbangan → troli kekal kosong → watak berfikir → 3 langkah (siapa → uji → besarkan) → troli penuh → watak senyum yakin |
| **Visual** | Watak di pentas gelap, objek 3D/2.5D (telefon dengan butang BOOST, dompet, syiling, hati, troli), Signal Line melukis pelan |
| **Signature Character** | **Watak utama**: bereaksi, memandang objek, berfikir, senyum |
| **CTA** | DM LOKADIGITAL |

### C02 ★ — "Viral Macam Bunga Api" (SAMPLE 02 · cinematic 3D)
| | |
|---|---|
| **Hook** | Bunga api meletup di atas laut gelap; semua bot berpaling ke arahnya |
| **Insight** | Viral terang tapi sekejap. Strategi ialah cahaya yang konsisten, yang membawa pelanggan pulang setiap hari |
| **Audiens** | Semua business owners |
| **Objektif** | Edukasi: content viral vs sistem (sambungan kepada EP03) |
| **Storytelling** | Bunga api → bot berkumpul → api padam → bot hanyut → rumah api menyala → pancaran kuning berputar → bot mengikut ke pelabuhan yang bercahaya |
| **Visual** | Adegan 3D sebenar: laut, langit, bot, bunga api (lavender/putih), rumah api (kuning = signal), pelabuhan; kamera dolly, crane, follow |
| **Signature Character** | Tiada (metafora tulen) |
| **CTA** | DM LOKADIGITAL |

### C03 ★ — "Funnel You Bocor" (SAMPLE 03 · motion graphics + infographic)
| | |
|---|---|
| **Hook** | Ribuan titik "views" mengalir masuk ke paip, tetapi hanya setitik sampai ke bawah |
| **Insight** | Masalah bukan kurang views. Pelanggan bocor di setiap peringkat: hook lemah, offer tak jelas, lambat reply, tiada follow-up |
| **Audiens** | SME, beauty, consumer brands |
| **Objektif** | Edukasi funnel, dan tunjuk LokaDigital berfikir secara sistem |
| **Storytelling** | Aliran masuk → 4 kebocoran dikenal pasti satu demi satu → 4 tampalan → aliran penuh sampai ke "BELI" |
| **Visual** | Diagram paip bertingkat, zarah cecair, label kebocoran, ikon tampalan, meter hasil tanpa angka |
| **Signature Character** | Tiada |
| **CTA** | DM LOKADIGITAL |

### C04 — "Sedap Tapi Tak Buat Lapar" (F&B)
| | |
|---|---|
| **Hook** | Gambar makanan rata dan pucat di skrin telefon; ibu jari scroll lalu |
| **Insight** | Content F&B gagal bukan kerana makanan, tetapi kerana tiada rasa *keinginan*: wap, tekstur, bunyi, momen |
| **Audiens** | F&B owners |
| **Objektif** | Edukasi creative content F&B |
| **Storytelling** | Pinggan statik → "tambah" wap, cahaya, tekstur dan gerak satu demi satu → ibu jari berhenti |
| **Visual** | Makro 3D pinggan berputar, zarah wap, pencahayaan bertukar dari rata ke sinematik, split-screen sebelum/selepas |
| **Signature Character** | Cameo: watak muncul di hujung, terliur (ekspresi terkejut ke senyum) |
| **CTA** | DM LOKADIGITAL |

### C05 — "Bukan Sekadar Before–After" (Beauty & Skincare)
| | |
|---|---|
| **Hook** | Cermin retak dengan label "BEFORE / AFTER" yang diulang-ulang |

| **Visual** | Cermin 3D, pantulan berlapis, botol skincare generik, cahaya lembut |
| **Signature Character** | Tiada |
| **CTA** | DM LOKADIGITAL |

### C09 — "Organic vs Ads: Siapa Buat Apa?" (Education · teaser EP03)
| | |
|---|---|
| **Hook** | Dua pelari di garisan: "ORGANIC" dan "ADS" |
| **Insight** | Organic menguji, ads membesarkan. Mereka satu pasukan, bukan pesaing |
| **Audiens** | Wellness & consumer brands |
| **Objektif** | Edukasi, dan teaser EP03 |
| **Storytelling** | Organic berlari dahulu dengan 3 baton (content) → satu baton bercahaya (pemenang) → diserahkan kepada ADS → ADS memecut |
| **Visual** | Trek 3D stylized, baton bercahaya, Signal Line sebagai trek |
| **Signature Character** | Tiada (atau cameo sebagai jurulatih) |
| **CTA** | DM LOKADIGITAL |

### C10 — "Sistem, Bukan Nasib" (Brand manifesto)
| | |
|---|---|
| **Hook** | Dadu dilempar dan bergolek, kemudian berhenti |
| **Insight** | Marketing tanpa sistem ialah perjudian. LokaDigital membina sistem yang boleh diulang |
| **Audiens** | Semua |
| **Objektif** | Brand authority |
| **Storytelling** | Dadu → bertukar menjadi gear → gear bersambung jadi mesin CONTENT → TEST → WINNER → ADS → SCALE → watak menekan suis, mesin berjalan |
| **Visual** | Objek 3D bertransformasi, mesin mekanikal minimal, kinetic typography |
| **Signature Character** | Penutup: menekan suis, senyum yakin |
| **CTA** | DM LOKADIGITAL |
