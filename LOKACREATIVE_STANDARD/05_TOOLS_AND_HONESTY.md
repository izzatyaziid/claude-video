# 05 · Tools & Honesty

## Keupayaan sebenar (persekitaran Claude Code cloud, 2026-11-25)
| Tahap | Apa |
|---|---|
| ✅ Kuat | Strategi, konsep, copy BM/EN, storyboard; website (HTML/CSS/JS, React, GSAP, three.js); motion graphics, kinetic type, infografik; tipografi 3D (opentype.js → three.js); suntingan/pemasangan footage yang dibekalkan; QC automatik |
| ⚠️ Terhad | Adegan 3D (render CPU, lambat, tiada GPU); watak rig 2.5D dari satu gambar; muzik disintesis (bukan bertaraf studio) |
| ❌ Tiada | Imej/video AI (tiada kredit), fotografi, footage, model watak 3D penuh, perpustakaan muzik/SFX berlesen; Unsplash/Pexels/Freesound disekat; Canva disekat |

## Routing
- **Buat dengan kod:** typography, data, UI, abstrak, 3D stylized ringkas, tekstur prosedural.
- **Perlukan aset luar:** foto produk/tempat sebenar, footage, muzik berlesen, watak 3D penuh. Minta awal dari klien atau pasukan.

## Polisi kejujuran
- Setiap output dilabel: **konsep · animatic · production test · final**.
- Nyatakan had dengan spesifik. Jangan guna perkataan "premium" atau "sinematik" untuk kerja yang tidak lulus rubrik.
